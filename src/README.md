# 前言

這本書寫給完全沒打過橋牌的人。你只需要認得撲克牌。

多數橋牌教材會直接告訴你「12 點開叫」、「高花要五張」。這些都對，但背起來很無聊，也很容易忘。這本書換一個方向：先把**規則**和**計分**講清楚，再從計分一步一步*推導*出這些原則。你會發現，叫牌的約定大多可以從計分表推出來。

全書的路線是：

1. **規則**：怎麼出牌、怎麼叫牌、怎麼算分。
2. **從規則到策略**：為什麼要叫成局、為什麼要數大牌點、為什麼要找八張王牌。
3. **自然叫牌**：開叫、答叫、再叫。
4. **二蓋一**：現代最流行的叫牌架構，細節以 [Bridge World Standard 2017][bws] 為準。
5. **競叫**：敵方也叫牌的時候怎麼辦。

讀完之後，你應該可以和一般牌友坐下來打一場複式橋牌，大部分的牌都知道自己在做什麼。

## 怎麼讀

- 橋牌是打出來的。每讀完一章，找三個朋友，或上 [Bridge Base Online](https://www.bridgebase.com/) 打幾副牌。
- 術語第一次出現時會用**粗體**，並附上英文。全部整理在[術語對照](glossary.md)。
- 想先看影片的話，洪介興老師的[冷光橋藝教室](https://www.youtube.com/watch?v=F2aTonsHemI)是很好的起點，本書前幾章的範圍和它的第一級相近。

## 本書沒講的：打牌

這本書幾乎只講叫牌。合約叫定之後，莊家怎麼吃到夠多的磴、防家怎麼擊垮合約，書裡沒有教。這部分請讀葉庭佑為台大橋藝社寫的 [BTU 新生橋牌教學](https://hackmd.io/@TpKotoba/SypU525Ffx)。它是社課的講義，不必上過課，自己讀就能懂。

講義分成兩個部門：

- **迷你橋牌**：沒有叫牌。四家報出大牌點，點數多的一方主打，莊家看著夢家的牌直接選合約。內容從規則開始，接著是主打技巧（建立長門、偷牌、讓送、扣住、王吃建立、短邊王吃、緊急墊牌），最後是怎麼選合約。想把牌打好，從這裡讀起。
- **合約橋牌**：加上叫牌，可以和本書對照著讀。第一章後半有防禦的練習，例如第三家什麼時候不上大牌、首攻雙張找王吃。

講義把「磴」寫作「墩」，是同一個東西。

[bws]: https://www.bridgeworld.com/pages/readingroom/bws/bwscompletesystem.html
