# 前言

這本書寫給完全沒打過橋牌的人。你只需要認得撲克牌。

多數橋牌教材會直接告訴你「12 點開叫」、「高花要五張」。這些都對，但背起來很無聊，也很容易忘。這本書換一個方向：先把**規則**和**計分**講清楚，再從計分一步一步*推導*出這些原則。你會發現叫牌的約定大多不是誰規定的，而是計分表逼出來的。

全書的路線是：

1. **規則**：怎麼出牌、怎麼叫牌、怎麼算分。
2. **從規則到策略**：為什麼要叫成局、為什麼要數大牌點、為什麼要找八張王牌。
3. **自然叫牌**：開叫、答叫、再叫。
4. **二蓋一**：現代最流行的叫牌架構，細節以 [Bridge World Standard 2017][bws] 為準。
5. **競叫**：敵方也叫牌的時候怎麼辦。

讀完之後，你應該可以和一般牌友坐下來打一場複式橋牌，大部分的牌都知道自己在做什麼。

## 怎麼讀

- 橋牌是打出來的。每讀完一章，找三個朋友，或上 [Bridge Base Online](https://www.bridgebase.com/) 打幾副牌。
- 術語第一次出現時會用**粗體**，並附上英文。全部整理在[術語對照](glossary.md)。
- 想先看影片的話，洪介興老師的[冷光橋藝教室](https://www.youtube.com/watch?v=F2aTonsHemI)是很好的起點，本書前幾章的範圍和它的第一級相近。
