# 術語對照

| 中文 | 英文 | 說明 |
|---|---|---|
| 磴 | trick | 四人各出一張牌為一磴 |
| 引牌 | lead | 一磴的第一張牌 |
| 首引 | opening lead | 整副牌的第一張牌 |
| 跟牌 | follow suit | 出和引牌相同的花色 |
| 墊牌 | discard | 沒牌可跟時出其他花色 |
| 王牌 | trump | 比其他花色都大的花色 |
| 王吃 | ruff | 沒牌可跟時出王牌 |
| 清王 | draw trumps | 引王牌把敵方的王牌逼出來 |
| 無王 | notrump (NT) | 沒有王牌的合約 |
| 高花 | major | ♥ 和 ♠ |
| 低花 | minor | ♣ 和 ♦ |
| 叫品 | bid | 線位加花色或無王 |
| 線位 | level | 叫品的數字，加 6 為磴數 |
| 派司 | pass | 不叫 |
| 賭倍 | double (X) | 加大敵方合約的輸贏 |
| 再賭倍 | redouble (XX) | 再加大被賭倍合約的輸贏 |
| 合約 | contract | 最後一個叫品 |
| 莊家 | declarer | 主打合約的人 |
| 夢家 | dummy | 莊家的同伴，攤牌 |
| 防家 | defender | 莊家的敵方 |
| 做成 | make | 吃到合約要求的磴數 |
| 倒約 | go down | 沒吃到合約要求的磴數 |
| 超磴 | overtrick | 超過合約的磴 |
| 部分合約 | partscore | 磴分不到 100 的合約 |
| 成局 | game | 磴分 100 以上的合約 |
| 小滿貫 | small slam | 六線合約 |
| 大滿貫 | grand slam | 七線合約 |
| 身價 | vulnerability | 影響獎分與罰分的狀態 |
| 複式橋牌 | duplicate bridge | 同一副牌多桌重複打並比較成績 |
| 大牌點 | high-card points (HCP) | A = 4、K = 3、Q = 2、J = 1 |
| 牌型 | shape, distribution | 四門花色的張數 |
| 平均牌型 | balanced hand | 4–3–3–3、4–4–3–2、5–3–3–2 |
| 配合 | fit | 兩手合計八張以上 |
| 擋張 | stopper | 能阻止敵方連吃一門花色的大牌 |
| 開叫 | opening bid | 第一個叫品 |
| 答叫 | response | 開叫者同伴的叫品 |
| 再叫 | rebid | 同一人的第二次叫牌 |
| 自然叫 | natural bid | 意思和字面相同的叫品 |
| 特約叫 | convention | 意思另有約定的叫品 |
| 轉換叫 | transfer | 叫低一級的花色，請同伴叫出你的長門 |
| 止叫 | sign-off | 請同伴派司 |
| 邀請 | invitational | 請同伴高限再叫 |
| 迫叫 | forcing | 同伴不可派司 |
| 迫叫成局 | game forcing (GF) | 成局之前雙方都不派司 |
| 二蓋一 | two-over-one (2/1) | 二線新花答叫為迫叫成局的架構 |
