# 叫牌

上一章最後留下一個問題：王牌由誰決定？答案是用競標的。哪一對願意承諾吃比較多磴，哪一對就有權決定王牌。這個競標過程叫做**叫牌** (auction)。

## 叫品

競標時喊出來的每一個價碼叫做**叫品** (bid)，由一個數字和一門花色（或無王）組成，例如 1♠、3NT、4♥。

數字稱為**線位** (level)，從 1 到 7。線位不是磴數，要加上 6 才是：

> 線位 <var>n</var> 的意思是「我們要吃 6 + <var>n</var> 磴」。

所以 1♠ 是「以黑桃為王牌，吃 7 磴」，3NT 是「打無王，吃 9 磴」，7NT 是 13 磴全吃。一副牌有 13 磴，吃到 7 磴才過半，所以競標從 7 磴起跳很合理。

## 叫品的高低

後叫的叫品必須比前面的高。線位高的叫品比較高。線位相同時比花色：

> ♣ < ♦ < ♥ < ♠ < NT

所以全部 35 個叫品排成一道階梯：

> 1♣ 1♦ 1♥ 1♠ 1NT 2♣ 2♦ …… 7♥ 7♠ 7NT

有人叫了 1♥ 之後，你可以叫 1♠ 或 1NT，但想叫梅花就得叫 2♣。

花色的順序很重要，後面會一直用到。♥ 和 ♠ 稱為**高花** (major)，♣ 和 ♦ 稱為**低花** (minor)。

## 叫牌的流程

從發牌的人開始，順時針輪流。輪到你的時候有四種選擇：

- 叫一個比目前更高的**叫品**。
- **派司** (pass)：這一輪不叫。之後輪到你時還是可以再叫。
- **賭倍** (double，記作 X)：對敵方剛叫的叫品說「你們做不到」，輸贏都加大。
- **再賭倍** (redouble，記作 XX)：被敵方賭倍之後說「我們做得到」，輸贏再加大。

有人叫牌之後，連續三家派司，叫牌就結束。如果一開始四家都派司，這副牌就不打，雙方零分。

## 合約、莊家、夢家

最後一個叫品成為**合約** (contract)。叫到合約的那一對必須吃到承諾的磴數：吃到了是**做成**，沒吃到是**倒約**，差幾磴就說「倒幾」。

看一個例子。南發牌：

| 西 | 北 | 東 | 南 |
|:---:|:---:|:---:|:---:|
|      |      |      | 1♠   |
| Pass | 2♠   | Pass | 4♠   |
| Pass | Pass | Pass |      |

合約是 4♠：南北要以黑桃為王牌吃 10 磴，東西則要想辦法吃到 4 磴讓合約倒掉。

接下來決定誰主打：

- **莊家** (declarer)：合約那一對之中，**最先**叫出合約花色的人。上例是南。
- **首引** (opening lead)：莊家左手邊的人引第一張牌。上例是西。
- **夢家** (dummy)：莊家的同伴。首引之後，夢家把 13 張牌全部攤在桌上，由莊家指揮怎麼出。上例是北。
- **防家** (defenders)：另外一對。上例是東西。

所以實際打牌時，莊家一個人打兩手牌，而且每個人都看得到夢家的牌。

## 只有 38 個詞

叫牌的時候不能交談，不能用語氣或表情暗示。你和同伴之間唯一合法的溝通，就是 35 個叫品加上派司、賭倍、再賭倍。

換句話說，叫牌是一種只有 38 個詞的語言。你要用它告訴同伴你的牌長什麼樣子，而且敵方全程都聽得到。這本書的後半部都在講這種語言怎麼說。

## 重點

- 線位加 6 等於要吃的磴數。
- 花色高低是 ♣ < ♦ < ♥ < ♠ < NT。
- 連續三家派司，最後的叫品成為合約。
- 最先叫出合約花色的人是莊家，莊家左手邊首引，莊家的同伴攤牌當夢家。
