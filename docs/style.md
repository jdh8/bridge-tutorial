# 文風：去 AI 味和翻譯腔

2026-10-17 掃過全書。古典翻譯腔（並非、進行、作為、對於、透過、確保、然而、換言之、事實上、破折號）全部是零；「被」只出現在「被賭倍」「被派司」這類術語。剩下的 AI 味在**句型**，不在用詞。每章結尾的「> **一句話結論**」和「## 重點」是教材結構，不算。

列出候選行的指令：

```sh
grep -nP '為什麼[^？]{0,20}？|不是.{1,12}而是|這就是|正是|同一個道理|同樣的道理|理由是|原因是|代價是|問題是|答案是' src/*.md src/*/*.md | grep -v deals.md
```
