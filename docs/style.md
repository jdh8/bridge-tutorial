# 文風：去 AI 味和翻譯腔

2026-10-17 掃過全書。古典翻譯腔（並非、進行、作為、對於、透過、確保、然而、換言之、事實上、破折號）全部是零；「被」只出現在「被賭倍」「被派司」這類術語。剩下的 AI 味在**句型**，不在用詞。每章結尾的「> **一句話結論**」和「## 重點」是教材結構，不算。

列出候選行的指令：

```sh
grep -nP '為什麼[^？]{0,20}？|不是.{1,12}而是|這就是|正是|同一個道理|同樣的道理|理由是|原因是|代價是|問題是|答案是' src/*.md src/*/*.md | grep -v deals.md
```

## 待辦

依優先順序，一項一項處理。做完的項目直接刪，全部做完就刪掉這個文件，歷史在版控裡。

- **「不是 X，而是 Y」**（11 處）。定義句留著（「賭倍不是處罰，而是……」在粗體結論裡沒問題），敘述裡順手用的改掉：`slam/trump.md:24`、`opener.md:148`、`slam.md:22`、`semiforcing.md:125`、`balancing.md:87`。
- **回扣句「這就是……」「正是……」「和 X 是同一個道理」**（約 24 處）改掉一半。`major.md:103-105` 兩句連用；`two-over-one.md:68`、`78`；`1nt.md:144`、`197` 同一句「是同一個道理」出現兩次；`game-force.md:22`、`2c.md:129`、`balancing.md:41`、`interference.md:19`。
- **短主題句「理由是……」「代價是，……」「問題是……」**（約 15 處）是英文 "The reason is X." 的影子，全改。`2c.md:78`「理由是空間。」、`fit.md:71`「代價是，」、`overcall.md:163`、`2c.md:9`、`semiforcing.md:19`、`raises.md:43`「答案往往不在點數，而在短門」一句中了兩種。
- **路標「這一章 / 那一章 / 上一章 / 下一章 / 前面 / 後面」**（約 170 處）。只挑最密的 `slam.md` 和 `game-force.md`。`fit.md:3` 和 `1nt.md:3` 開頭幾乎同一句「這一章……另一個問題：打什麼」，像套模板，改掉一個。
- **散文裡的分號「；」**（約 111 處）。台灣白話少用分號，「X；Y」多半能拆成兩句。低優先。

行號是掃描當天的，改過之後以 grep 為準。
