# 影片系列的素材評估

2026-10-11 把整本書當 YouTube 教學影片的素材審過一遍。結論：內容足夠，形式不夠。第一到三部幾乎可以逐章改寫成腳本；第四、五部內容夠但份量過大，數字和術語還沒定案，先錄會被鎖死。全書沒有任何圖像素材，影片需要的視覺層要從零做。

後來方向改成互動練習，見[互動練習](interactive.md)。這份評估留著，打牌示範仍然可能拍成影片。

## 可以直接用的

- **章節結構就是腳本結構。** 每章都是：開頭問題、從計分推導、粗體規則、例牌、整理表、重點。對應到影片是 cold open、正文、暫停作答、片尾卡。敘述已經用「你」對話，不必重寫口吻。
- **一條貫穿全書的算術**：24 點成局、12 + 12、弱／邀請／成局三區。這是整個系列的 motif，每集都能回扣。
- **練習表是現成的測驗段落**，答案連理由都寫好了。
- **32 副牌是現成的分鏡**：每個叫品一條解說、附連結，雙夢家驗證過。可做 32 支短片，或穿插進對應的章節。
- **術語有英文對照**，字幕和影片說明直接用。

## 要補的和風險

- **份量差五倍。** 第一、二部每章 1.3--2.3k 字，一集 6--8 分鐘剛好。第三部起每章 4--9k 字：敵方蓋叫之後 9k、迫伴賭倍和竄叫各 8.3k、強牌開叫 8k。這些一章要拆 3--4 集。1NT 那章的整理表有 10 種答叫，一支影片放不下。
- **零視覺素材。** repo 裡只有 CSS 和字型。牌是 `♠AK752 ♥84` 這種文字，影片要牌圖、四家牌桌、叫牌過程動畫、計分表。`deals.py` 已經會解析牌並輸出 PBN，從同一份資料產生 SVG 是最省力的路。
- **完全不講打牌。** 書把打牌交給 BTU 講義，零基礎的影片觀眾會期待看到真的出一磴。影片可以改交給[冷光橋藝教室](https://www.youtube.com/watch?v=F2aTonsHemI)：很久沒更新，但打牌的基礎還在，不必自己重拍。至少第一集還是要示範幾磴，「試試看」改成螢幕上打一副。
- **第三部教的是暫時版。** 第三部有 10 處「留到第四部」：先叫新花再叫 4♠ 之後被 Jacoby 2NT 取代，1NT 不迫叫之後變半迫叫，1♦ - 1♠ - 2♣ 的 12--17 點在二蓋一之後沒有上限。書裡可以點連結，影片觀眾看到第三部就走，學到的是另一套。要決定是每集標明「暫時版」，還是把 Jacoby 2NT 提前。還沒決定。
- **數字沒定案。** [第四部](part4.md)和[第五部](part5.md)都寫「多數還沒定案」，[強牌 2♣](strong-2c.md) 和 BWS 差最多。錄成影片就改不了，留言區也會拿冷光的 20--21 點 2NT 來比。

## 錄製順序

1. 先錄第一、二部，七集：數字穩定、份量剛好、最需要視覺示範。
2. 第三部拆集後錄，實戰篇的第三部題目（1、5、6、12、14、16、18、21、23、30、31 副）穿插。
3. 第四、五部先定案數字和術語，再拆集錄。
