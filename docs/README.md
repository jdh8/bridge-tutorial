# 設計筆記

`src/` 是給新生看的書。這裡記的是寫書時的討論：制度為什麼這樣取捨、和 BWS 差在哪裡、哪些數字還沒定案。這些內容對新生太細，所以不會 build 進書裡，留給想知道來龍去脈的人。

- [點數範圍](ranges.md)：平均牌型的階梯、低花開叫之後的無王答叫、高花加叫，以及它們和 BWS 的差異。
- [強牌 2♣](strong-2c.md)：照點數分段、不用 Birthright 和雙重負性的 2♣ 結構，附牌型統計。
- [二蓋一的風格](two-over-one.md)：牌力派和牌型派，各家怎麼定開叫者的再叫，本書選了什麼。
- [第四部的數字](part4.md)：BWS 沒有給數字、本書自己選的範圍，多數還沒定案。
- [第五部的數字](part5.md)：蓋叫和迫伴賭倍的點數範圍、和 BWS 的差異，多數還沒定案。也記了迫伴賭倍的歷史考證和處罰的模擬。
- [術語](terminology.md)：台灣的用語、哪些約定保留英文、哪些譯名還沒查證。
- [資料來源](sources.md)：BWS 原文、歷史文獻和 ../pons 的雙夢家統計。

排版規則和書一樣，見 [CLAUDE.md](../CLAUDE.md)。
